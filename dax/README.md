# DAX documentation

Files in this folder:

- `measure-inventory.csv` — measures and fields visible in the report, with formula availability.
- `measure-definitions.md` — measure descriptions and source limitations.
- `measures-reference.dax` — a DAX reference file listing the names visible in the report.

The PDF does not expose original DAX formulas or model schema. No formulas have been guessed and presented as original. To populate this folder with the actual expressions, the editable PBIX or an export of its model measures is needed.
