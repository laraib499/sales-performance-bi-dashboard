# Dashboard deliverables

This folder is the home for the two project deliverables supplied for this portfolio project:

- `Sales_Performance_BI_Dashboard.pbix` — editable Power BI report.
- `Sales_Performance_BI_Dashboard.pdf` — nine-page static export/preview.

Open the PBIX in Microsoft Power BI Desktop to explore the report interactively. The PDF is useful for a quick read-only review.

If the model requests credentials or a source file, reconnect the authorized data source. The source dataset is not bundled here; do not publish restricted or customer-identifiable data.
